# AutoCite Chrome Extension

AutoCite is a Chrome Extension that helps students automatically create citations by simply copying text from an online source. It opens in a sidebar and generates full citations, in-text citations, citation history, and bibliography export.

## Features

* Automatically detects copied text from online sources
* Generates citations for:

  * APA 7th edition
  * MLA 9th edition
  * Chicago Author-Date style
* Supports source types such as:

  * Website
  * PDF
  * Book
  * Journal Article
* Generates full citation and in-text citation
* Lets users copy text with in-text citation
* Saves citation history locally
* Allows editing and deleting saved citations
* Exports bibliography in alphabetical order
* Uses local browser storage for privacy

## Privacy

AutoCite does not upload copied text, citations, or browsing data to any server. Citation data is stored locally in the user’s browser.

## How to Install and Test in Chrome

1. Download or clone this repository.
2. Make sure the folder contains `manifest.json`.
3. Open Google Chrome.
4. Type this in the address bar: `chrome://extensions/`
5. Turn on **Developer mode** at the top right.
6. Click **Load unpacked**.
7. Select the main **AutoCite extension folder**.
8. The extension should now appear in Chrome.
9. Pin the extension by clicking the puzzle icon beside the address bar.
10. Open any website, copy text, then open AutoCite to test the sidebar and citation features.

## Important Note

Do not upload the ZIP file directly to Chrome Extensions. Extract the ZIP first, then select the folder that contains `manifest.json`.
